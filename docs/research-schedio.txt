3. Core Questions Answered
Q1: Fastest way to interact with Google Calendar API for free?

Use chrome.identity.getAuthToken. In the Google Cloud Console, you create an OAuth client ID with the type "Chrome App." This allows the extension to retrieve a token directly from the user's logged-in Chrome profile without redirecting to a web server or managing secret keys.

Q2: Best Free LLM API for JSON parsing?

Google Gemini 1.5 Flash is the current winner for zero-budget developers.

JSON Reliability: High (supports "JSON Mode").

Cost: $0 (Rate limits: 15 RPM / 1M TPM).

Access: Google AI Studio (Instant API key, no CC).

Q3: Mac Integration: Tauri, Electron, or Shortcuts?

Recommendation: Chrome Global Shortcut + Raycast.

Tauri/Electron: Too high a learning curve for a 5-day deadline. You'll spend 3 days just setting up IPC and OAuth in a desktop environment.

Chrome Global Shortcut: Add a commands key to manifest.json. Users can map a hotkey (e.g., Cmd+Shift+E) that works even when Chrome is in the background.

Raycast: If you need a "native" feel, Raycast extensions are built in React/TS. You can call the same Gemini API from Raycast to provide a "Calendar Magic" command in the Mac spotlight search.

Q4: Handling OAuth 2.0 without a backend?

In Manifest V3, the "callback" is handled internally by Chrome.

Set identity permission in manifest.json.

In Google Cloud Console, whitelist your Extension ID (the ID found in chrome://extensions).

The redirect URI is automatically: https://[EXTENSION_ID].chromiumapp.org/.

6. Mac Integration: Comparison
Method	Dev Effort	Native Feel	Pros/Cons
Chrome Global Shortcut	Low (10 mins)	Medium	Pros: Works everywhere if Chrome is open. Cons: No "Menu Bar" icon.
Raycast Extension	Medium (4 hours)	High	Pros: Best native Mac experience for JS devs. Cons: User must have Raycast installed.
Electron Wrapper	High (2 days)	High	Pros: Complete control. Cons: Huge bundle size; overkill for a prototype.

The 80/20 Strategy: Focus 100% on the Chrome Extension functionality first. Use the Global Hotkey for the "Mac Integration" requirement on Day 5. It fulfills the prompt's requirement with zero extra code besides a few lines in the manifest.

7. Security Note

Managing API Keys: Since this is a client-side prototype, your Gemini API key will be exposed in the bundled JS.

For the 5-Day Prototype: Hardcode the key but never publish to the Web Store.

For Production: Use Cloudflare Workers (Free Tier) as a 5-line proxy to hide the key.
